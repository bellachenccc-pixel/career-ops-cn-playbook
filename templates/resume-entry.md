# 结构化简历条目模板

## 基本结构

```text
公司｜岗位                                      YYYY.MM - YYYY.MM
• 能力标题｜业务背景 + 关键动作 + 方法 + 可验证结果
• 能力标题｜业务背景 + 关键动作 + 方法 + 可验证结果
```

## 填写顺序

1. 先写业务问题，不要先写工具。
2. 写清自己负责的动作，不把团队成果全部归为个人成果。
3. 方法只保留能证明能力的部分。
4. 结果优先使用已确认数字；数字不可靠时使用定性结果。
5. 为每条经历添加一个能够独立阅读的标题。

## 标题检查

一个合格的标题应该：

- 让招聘经理在 3 秒内知道这条经历证明什么。
- 与目标 JD 的核心职责有关。
- 不重复公司名或岗位名。
- 不使用“负责相关工作”“完成领导安排”等空泛表达。

## 示例

以下内容为虚构示例：

```text
某消费科技公司｜区域运营经理                  2024.05 - 2026.04
• 全球市场商业化｜完成多个国家的市场与渠道分析，推动区域站点从 0 到 1 上线，并建立上市后的经营复盘机制。
• AI 内容生产提效｜针对多 SKU 和设计资源有限的问题，引入生成式 AI 优化图片与视频链路，缩短制作周期并提升素材复用率。
• 渠道全链路运营｜建立准入、上架、首销、补货和复盘闭环，协同销售、市场与供应链解决关键渠道卡点。
```

## 事实校验

提交前逐项检查：

- [ ] 公司、岗位和任职时间准确。
- [ ] 每个数字都有原始依据。
- [ ] 没有把“参与”写成“主导”。
- [ ] 没有把工具使用写成工具开发。
- [ ] 没有为了匹配 JD 增加未做过的工作。
- [ ] 所有工作经历条目都有标题。
